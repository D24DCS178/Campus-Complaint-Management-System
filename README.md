# Campus Complaint Management System with Automated CI/CD Pipeline

## Project Overview

A DevOps-focused MERN Stack application developed as part of a Summer Internship. The project demonstrates a complete software development lifecycle, including Git workflow, Docker containerization, Docker Compose, GitHub Actions CI/CD, and deployment practices.

---

## Tech Stack

### Frontend
- React (Vite)
- Tailwind CSS
- React Router DOM
- Axios

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### DevOps
- Docker
- Docker Compose
- GitHub Actions
- Git
- GitHub
